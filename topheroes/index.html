7. Магазины #

Снимок после вступления в ATM: 1335 Guild Points осталось после покупок.

Guild Store — Guild Points

Vault Keys = №1. Гайды по текущей версии прямо рекомендуют выкупать ключи; Guild Vault — источник Titan Marks для gear.

  • На скрине дешёвый Vault Key уже 0/4.
  • Rare Pet Egg также 0/3.
  • Справа остаётся ещё Vault Key по 500, лимит 30/30.

Что после ключей

Следом в daily-приоритете: Refined Metal → Magic Stone → Pet Food. Stamina Potion — полезный запас под события/фарм.

Что пропускать

Server Transfer Scroll, Advanced Relocate, timber/resources — не текущий приоритет. Diamonds не важнее ключей.

Что делать с 1335 сейчас

Не сливай остаток вслепую. Открой Guild Vault, используй уже купленные ключи и пришли скрин самого Vault/награды. Если ключ за 500 — тот же расходник для Vault, его будем докупать по мере притока Guild Points.

Остальные магазины

Points Store — ежедневно; Trade Store — когда накопилась trade-валюта/есть конкретная цель; Guild Honor — беречь под Soul Stones и другие редкие сезонные позиции.

11. О чём ещё думать #

Вещи, которые легко пропустить.

Guild Vault → gear

Vault Keys важны не сами по себе: через Guild Vault добываются Titan Marks, усиливающие gear по фракциям.

Events как множитель

Stamina, shards, gear-материалы и speed-ups выгоднее тратить в окно события, которое платит за то же действие.

Break-points

Полная звезда, новый skill, awakening tier или gear breakpoint обычно важнее нескольких микроплюсов.

Power ≠ качество

Состав, роли, синергия и survivability могут быть важнее красивой цифры power.
