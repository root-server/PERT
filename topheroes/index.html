1. С чего вообще думать #

Если глаза разбегаются — проходи этот список сверху вниз и не открывай следующую тему, пока предыдущая не требует решения.

Порядок принятия решений

  1. Main pack. Сейчас это 6 героев League. Не строим три равные пачки.
  2. Мясо. Текущий главный дефицит: уровни дают больше пользы, если концентрировать их в core.
  3. Skills / stars. Усиливаем героев, которые переживут ближайшие замены.
  4. Шмот. Лучший шмот и крафт идут в main carry / front, а не по стрелочкам power.
  5. Stamina. Limited boss loot — пока он ценен; Fast Grind — когда задача именно мясо.
  6. Магазины. Валюта тратится только под заранее выбранную цель.
  7. Пачки 2–3. Получают остаточный ресурс, пока main не стабилен.

Три ближайших рычага

Astrologer → 170Knight вместо HostessПереход в ATM
ATM — первый текущий кандидат, который ответил и прямо подтвердил, что English-speaking игроки welcome.

Не приоритет

  • Догонять уровни всех героев
  • Качать Hostess только потому, что она уже 160
  • Тратить universal shards на временных героев
  • Поднимать вторую/третью пачку до уровня первой
  • Строить ресурсные шахты «потому что можно», если это не bottleneck

Правило нового скрина

Любой новый герой / новый слот / новый gear tier / переход в гильдию сначала обновляет этот лендинг, а уже после этого меняются решения.

4. Звёзды, Traits и Awakening #

После скринов стало видно, что «уровень героя» — только один из слоёв прогресса.

Звёзды

  • Personal shards core-героев использовать проще: они привязаны к конкретной цели.
  • Universal shards — не прожигать, чтобы просто закрыть маленький текущий шаг временного героя.
  • Secret Keeper / Treeguard / Windwalker — персональные шарды имеют понятную долгосрочную ценность.
  • Pyromancer сейчас упирается в персональные shards; универсалами форсить без break-point не надо.

Traits

  • Knight у тебя уже очень глубоко развит: 10 / 10 / 10 / 5.
  • Blacksmith: 5 / 5 / 5 / 3; Guard: 5 / 5 / 3; Pharmacist: 5 / 5 / 2.
  • Не путать «много открытых traits» с автоматическим приоритетом героя в основной пачке.
  • Пока не подтверждена точная область действия конкретного trait, не тратить universal shards на off-core traits.
Старое утверждение «все такие traits глобальные на аккаунт» считаем неподтверждённым и больше не используем как основание для расхода редких шардов.

Awakening Pyromancer

  • Сейчас Awakening закрыт звёздным порогом.
  • Валюты Awakening пока не являются текущей точкой решения.
  • Когда откроется — сначала смотрим текущую main-шестёрку и стоимость Tier 1, потом жмём.

Skill books — порядок

Pyromancer → Astrologer → Secret Keeper → Bard, если нет конкретного PvP/PvE break-point.

Pyromancer уже почти выжат по skills; поэтому новые книги всё чаще будут выгоднее на Astrologer/SK, чем на случайных secondary heroes.

5. Шмот и крафт #

Не «всем по комплекту», а лучшие предметы туда, где они меняют результат боя.

Приоритет

  1. Pyromancer — offensive pieces
  2. Secret Keeper / Knight — выживаемость фронта
  3. Astrologer — offensive pieces
  4. Bard
  5. Minister

Менять по одной вещи?

Да, если одна вещь реально лучше по нужным статам. Старое слишком жёсткое правило «не менять по одной» больше не используем.

  • Не держим слабый предмет только ради симметрии.
  • Но не реагируем автоматически на зелёную стрелку: смотрим роль героя.
  • Топовый предмет со secondary героя можно временно перекинуть в main, если режим это позволяет.

Крафт

Логика остаётся: сначала комплект/ключевые куски для main carry и front. Крафт вторых пачек начинается только когда новый предмет main-пачке почти ничего не даёт.

6. Мясо и stamina #

Главный bottleneck аккаунта. Здесь нужен строгий порядок.

Мясо — прямо сейчас

  1. Astrologer 160 → 170
  2. Minister 160 → 170
  3. Wilderness Hunter 90 → 120–150, уже после main
  4. Knight — только если именно фронт не держит; иначе не кормим временного танка выше необходимости

Stamina

  • Boss — пока есть нужные limited drops.
  • Fast Grind — когда задача именно мясо/idle resources.
  • Дополнительную stamina не прожигать автоматически вне события/понятной цели.

Fast Grind snapshot

На показанном уровне Idle Rewards было 15,600 meat/hour, а Fast Grind давал 120 минут наград за 20 stamina. Это хороший эталон для сравнения с текущим боссом, но цифра помечена как снимок, а не вечное правило.

7. Магазины #

Смотри не все вкладки подряд, а магазины с валютой, которую ты реально зарабатываешь регулярно.

Points Store

Смотреть ежедневно. Приоритет — hero shards / универсальные полезные предметы; не сливать валюту в сырьё.

Guild Store

Смотреть ежедневно после guild activities. Guild Points приходят из активности гильдии; дорогие редкие материалы ценнее случайных speed-ups.

Trade Store

Смотреть при обновлении/когда накопилась trade-валюта. Universal relic shards брать только когда понимаешь, какую реликвию докручиваешь.

Правило покупки

Перед покупкой: что это ускоряет? Если ответ не «main pack / bottleneck / конкретный break-point», покупку можно пропустить.

Короткая последовательность, чтобы не открывать всё меню игры подряд.

Каждый день

  1. Idle Rewards
  2. Guild: help / donate / activities
  3. Natural stamina: boss или Fast Grind по задаче
  4. Points + Guild Store
  5. Мясо в текущего приоритетного героя
  6. Только затем gear / events / вторые пачки

Раз в неделю / после крупного unlock

  • Проверить main-шестёрку
  • Проверить следующий крафт
  • Проверить star/skill break-points
  • Проверить гильдию
  • Обновить этот лендинг по новым скринам

Минимум за 2 минуты

Idle → Guild → stamina → shops → meat. Всё остальное можно пережить.

11. О чём ещё стоит думать #

Темы, о которых легко забыть, пока игра заваливает ресурсами.

Events как множитель

Speed-ups, stamina, star upgrades и большие пачки ресурсов выгоднее тратить в моменты, когда событие дополнительно платит за то же действие.

Break-points вместо «качать понемногу»

Новый skill level, полный star step, unlock awakening, новый gear tier — обычно важнее нескольких случайных микроплюсов.

Не путать power с качеством

Power полезен как индикатор, но состав, роль, синергия, skill levels и survivability могут быть важнее одной цифры.

Скринить то, что меняет решение

При новом герое лучше присылать: Level Up + Star + Skills/Traits + текущие пачки. Тогда обновление лендинга получается точным.

Карта мышления

1. Кто в main-6? → 2. Кто получает мясо? → 3. Какой следующий star/skill break-point? → 4. Что крафтится? → 5. Boss или Fast Grind? → 6. Что покупать? → 7. Только потом secondary packs.
